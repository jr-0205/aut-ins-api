## Definición de terminado

Una tarea puede marcarse como terminada cuando:

- Cumple su objetivo y criterios de aceptación.
- Está relacionada con una tarea del tablero.
- La documentación correspondiente fue actualizada.
- No contiene datos reales ni secretos.
- Fue revisada por otro integrante.
- Incluye evidencias o pruebas cuando corresponda.

El tablero Scrum es la fuente principal para responsables, fechas y estado diario. Este documento funciona únicamente como resumen estable.
