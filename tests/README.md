# Pruebas

La estrategia de pruebas se documentará en este directorio.

Como mínimo deberá cubrir:

- Inicio de sesión válido e inválido.
- Registro correcto del aspirante.
- Intento duplicado con CURP vigente.
- Carga y corrección documental.
- Dictamen aprobado, rechazado y observado.
- Conversión de aspirante aceptado en alumno.
- Generación de matrícula única.
- Inscripción con cupo disponible.
- Bloqueo de inscripción por grupo saturado.
- Acceso no autorizado a rutas protegidas.
- Casos de error y validaciones.

Las pruebas deberán utilizar datos ficticios.
