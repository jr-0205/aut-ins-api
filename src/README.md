# Código fuente

Este directorio recibirá el código de la API cuando se confirme el entorno de ejecución y comience la etapa de desarrollo.

La estructura interna deberá definirse después de aprobar:

- Arquitectura del backend.
- Framework y lenguaje definitivos.
- Convenciones de rutas, controladores y servicios.
- Manejo uniforme de errores.
- Validación de solicitudes.
- Estrategia de autenticación y autorización.

No deben agregarse módulos vacíos únicamente para aparentar avance.
