# Prisma

Este directorio contendrá el archivo `schema.prisma`, las migraciones y los datos de prueba cuando el modelo lógico y físico sea aprobado.

Antes de generar la primera migración deberán resolverse:

- Los nombres definitivos de los estados académicos.
- La relación del periodo con la inscripción.
- Las restricciones únicas de folio y matrículas.
- Los tipos y longitudes de cada atributo.
- La política de conservación del historial.

Nunca deberán incluirse cadenas de conexión reales.
